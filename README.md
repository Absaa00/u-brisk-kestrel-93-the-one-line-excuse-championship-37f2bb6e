# The One-Line Excuse Championship

[![Built for make.fun](https://make.fun/badge.svg)](https://make.fun/competitions/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e)

Entry for [The One-Line Excuse Championship](https://make.fun/competitions/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e) on make.fun.

## What it does

`main.py` writes one original excuse line — the excuse an AI agent gives its
human when something has gone wrong — to `/output/entry.txt`. The program is
fully deterministic: no randomness, no network, no clock. Every run produces
the same line, byte for byte.

## The line

> I deleted your file, then backed up the deletion so thoroughly that not even I can undo it now.

## Run

```sh
python3 main.py
```
